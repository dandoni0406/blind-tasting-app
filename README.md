# 🎯 블라인드 테이스팅

와인 모임에서 블라인드 테이스팅을 진행·기록하는 도구. 참가자별 추론(국가·지역·마을·등급·품종·빈티지)을 구조적으로 기록하고, 근접도 기반으로 자동 채점합니다.

와인 셀러 앱과 **독립적으로** 동작합니다 (DB 공유 안 함).

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:5173`

## 빌드 & 배포

```bash
npm run build
npm run preview
```

Vercel 배포는 와인 셀러 앱과 동일합니다 (README 참고). `vercel.json` 포함.

## 주요 기능

### 두 가지 진행 모드
- **🔒 미리 등록** — 혼자 진행하거나 한 명이 정답을 도맡아 관리. 정답을 먼저 입력하고 잠금.
- **🎉 공개 시 입력** — 여러 출제자 모임. 진행 중엔 정답 비공개, 와인을 하나씩 공개할 때 입력.

### 와인별 출제자(가져온 사람)
- 각 와인마다 누가 가져왔는지 지정
- 출제자는 자기 와인 추측에서 제외 (시음 평가만 작성)
- 적중률 계산에서도 자기 와인은 제외

### 계층형 입력 (표기 흔들림 방지)
- 국가 → 지역 → 마을 계층 선택 + 자동완성
- 산지 DB 내장 (13개국 / 68지역 / 288마을)
- 지역 선택 시 대표 품종 우선 표시, 등급 체계도 지역별로 표시

### 커스텀 채점 기준
- 항목별 가중치 슬라이더 (국가·지역·마을·등급·품종·빈티지)
- 빈티지 근접 허용 범위 (±1/2/3년), 근접 점수 비율 (30/50/70%)
- **와인별 채점 깊이** — "이 와인은 지역까지만, 저 와인은 마을까지" 설정 가능
- 자동 채점 후 출제자가 **± 수동 보정** 가능 (마이너 산지 가점 등)

### 결과
- 와인 순위 (평균 점수), 참가자별 추론 적중률 순위
- 와인별 정답 vs 각자 추론 비교 (정확 ✓ / 근접 ~ / 오답 ✗)

## 데이터 저장

브라우저 `localStorage` 에 세션이 누적 저장됩니다 (`src/storage.js`).

### 향후: 실시간 협업 (Firebase)

현재는 한 기기에서 진행하는 **통합형**입니다. 각 참가자가 자기 폰에서 추론을 입력하는 **협업형**으로 확장하려면:

1. `src/storage.js` 를 Firebase Firestore 로 교체
2. 세션마다 공유 링크 발급 (`/blind/:sessionId`)
3. 참가자는 링크로 게스트 참여 (가입 불필요), 자기 추론만 입력
4. 호스트만 정답 입력/공개

데이터 구조(`session.guesses[참가자][와인번호]`)가 이미 분산 입력을 염두에 두고 설계되어 있어, storage 레이어 교체 + 라우팅만 추가하면 됩니다.
